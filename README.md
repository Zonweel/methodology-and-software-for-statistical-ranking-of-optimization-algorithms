# methodology-and-software-for-statistical-ranking-of-optimization-algorithms
Методическое и программное обеспечение статистического анализа и ранжирования эффективности алгоритмов оптимизации на основе массовых вычислительных экспериментов

**Структура проекта**
- 📁 `data` — Исходные данные (CSV файлы, выгрузки).
- 📁 `figures` — Сгенерированные графики (boxplot, ранги).
- 📁 `ideas` — Схемы, макеты, картинки с идеями.
- 📁 `src` — Исходный код (скрипты блоков 1-5).
- 📁 `report` — Итоговые отчеты в формате DOCX.
